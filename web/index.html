M5Tools Web Flasher

Flash the M5Tools firmware onto an M5Stack Core2, Tough or ToughC5 straight from the browser. Nothing to install on the PC.

Your browser does not support Web Serial. Use Chrome, Edge or Opera on a desktop OS. Web Serial only works on HTTPS pages. Reload this page over HTTPS. The chip is detected automatically: an ESP32 gets the Core2 / Tough build, an ESP32-C5 gets the ToughC5 build.
  1. Connect the device to the PC with a USB data cable and switch it on.
  2. Press Connect, pick the serial port of the device, then press Install.
  3. Wait for the progress bar to finish. The device resets by itself into M5Tools.

If the port does not show up: on Core2 / Tough the USB bridge is a CP210x, on ToughC5 it is the chip's native USB. If the connection fails, hold the power button until the screen turns off, then try again while the device is booting.
